# Гайды aact

Практические разборы: описать архитектуру, прогнать проверки и метрики, ревью
diff в PR, гейт в CI, сверку схемы с задеплоенной реальностью, расширение своими
правилами и встраивание как библиотеки. Каждый гайд самодостаточен — команды,
реальный вывод, ничего лишнего.

Справочник команд, правил и форматов — в [`../reference/`](../reference/)
(генерируется из кода). Принципы и «почему» за правилами — в
[patterns.md](../../patterns.md) и [ADRs/](../../ADRs).

## С чего начать

- [**Быстрый старт**](./getting-started.md) — от нуля до зелёного `check` за пять
  минут: `init` → `check` → `--fix`, без установки.
- [**Моделирование под aact**](./modeling.md) — теги `acl` / `repo` / `relay`,
  boundaries и sync/async-связи: как описать архитектуру, чтобы правила
  срабатывали верно.
- [**Запуск проверки (`check`)**](./check.md) — анатомия нарушения, автофикс
  (`--fix` / `--dry-run`), три режима вывода, exit-коды.
- [**Настройка правил в конфиге**](./configuring-rules.md) — opt-in модель,
  опции правил, блок `analyze`.

## Обзор и анализ

- [**Метрики архитектуры (`analyze`)**](./analyze.md) — cohesion против coupling,
  sync/async, fan-in/out hotspot'ы, циклы.
- [**Каскадное снижение связанности (CCR)**](./cascade-coupling.md) — связанность
  не должна расти вверх по уровням иерархии; как выразить и проверить машинно.
- [**Разобраться в архитектуре (`view`)**](./explore-view.md) — интерактивная
  C4-карта, режимы Drill / Expand / Flat под задачу.
- [**Ревью diff в PR**](./review-diff.md) — `aact diff` и `aact view --diff`:
  что изменилось между двумя версиями модели.

## В CI и команде

- [**CI: SARIF → GitHub Code Scanning**](./ci-github-code-scanning.md) — aact как
  гейт на PR, нарушения как алерты в Security-вкладке.
- [**Соответствие архитектуры и реализации**](./architecture-conformance.md) —
  AaC ↔ IaC: дрейф между схемой и задеплоенной реальностью.
  `aact diff architecture.dsl ./k8s/`, линт манифестов, гейт на дрейф в CI.
